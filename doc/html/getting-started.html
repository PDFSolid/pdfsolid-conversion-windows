    Getting Started

    Deploy and initialize

    1. Reference lib/pdfsolidconversionsdk_dotnet.dll from the 1.3.0 SDK. Keep the matching native DLLs from lib/x64 or lib/x86 together and set your project to the corresponding process architecture. Do not mix x86 and x64 DLLs or use an older native SDK with the 1.3.0 managed assembly.
    2. Call LibraryManager.InitLibrary with the directory containing the native DLLs, then call LibraryManager.Initialize with the SDK resource directory. Verify a valid Windows license before converting. Stop on a load, initialization, or license failure.
    3. For the shipped x64 demo, open PDFSolid_Conversion_Demo.sln in Visual Studio. Use its x64 configuration and provide your Windows license.xml next to the executable. The project copies the x64 native DLLs and resources to the output directory.

    Convert Word (DOCX) to PDF

    Check IsWordToPDFSupported() on the loaded native library before converting. The example uses x64, resource, and license.xml next to the application; use x86 instead when deploying an x86 application. Supply an existing DOCX and a writable output path.

    using System;
using System.IO;
using PDFSolid_Conversion.Common;
using PDFSolid_Conversion.Conversion;

string appDir = AppDomain.CurrentDomain.BaseDirectory;
if (!LibraryManager.InitLibrary(Path.Combine(appDir, "x64")))
    throw new InvalidOperationException("Could not load the x64 native SDK.");

try
{
    if (!LibraryManager.Initialize(Path.Combine(appDir, "resource")))
        throw new InvalidOperationException("Could not initialize SDK resources.");

    ErrorCode license = LibraryManager.LicenseVerify(Path.Combine(appDir, "license.xml"));
    if (license != ErrorCode.e_ErrSuccess)
        throw new InvalidOperationException("License verification failed: " + license);

    if (!CPDFConversion.IsWordToPDFSupported())
        throw new NotSupportedException("The loaded native SDK does not expose Word to PDF.");

    var options = new WordOptions { PageRanges = "1-2", WordPdfBookmarkMode = WordPdfBookmarkMode.e_Headings };
    string diagnostics;
    ErrorCode result = CPDFConversion.StartWordToPDF("input.docx", "output.pdf", options, out diagnostics);
    if (result == ErrorCode.e_ErrUnsupportedFeature)
        Console.Error.WriteLine(diagnostics); // Check output=produced or output=not_produced before using the PDF.
    else if (result != ErrorCode.e_ErrSuccess)
        throw new InvalidOperationException("Conversion failed: " + result);
}
finally
{
    LibraryManager.Release();
}

    Omit WordOptions for all pages with no bookmarks. Word to PDF does not require loading a DocumentAI model. For supported options, the diagnostics overload and result handling, see the Word to PDF API and the Word to PDF guide. For PDF input, see the Conversion Guides and CPDFConversion class.
