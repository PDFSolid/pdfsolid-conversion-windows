    Introduction

    PDFSolid Conversion SDK 1.3.0 for Windows (.NET) supports both PDF export and Word (DOCX) to PDF.

    Conversion capabilities

    • PDF to Word (.docx), Excel (.xlsx), PowerPoint (.pptx), HTML, CSV, images, plain text, RTF, JSON, and Markdown.
    • PDF to Searchable PDF and OFD, with OCR and transparent text options where applicable.
    • Word (.docx) to PDF via StartWordToPDF. Select page ranges and optionally create PDF bookmarks from headings or Word bookmarks. Legacy .doc is not supported by this entry point.
    • Supported images can also be used as input for image conversion, including frame-by-frame conversion of multi-page TIFF.

    See Getting Started for deployment and your first conversion, the developer guide for workflows and options, and the CPDFConversion API for signatures and return codes.
